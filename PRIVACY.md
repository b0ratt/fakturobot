# Polityka prywatności / Privacy policy

**fakturobot** to prywatne narzędzie uruchamiane przez jego właściciela na własnym serwerze. Nie jest usługą dla innych osób.

- Bot korzysta z Gmail API wyłącznie z zakresem `gmail.send`: wysyła maile z fakturą z konta właściciela do jego księgowej oraz kopię archiwalną na to samo konto. Nie czyta, nie przeszukuje i nie usuwa żadnych wiadomości.
- Token dostępu Google jest przechowywany tylko na serwerze właściciela, w pliku dostępnym wyłącznie dla administratora. Nie jest przekazywany nikomu innemu.
- Bot nie zbiera danych innych osób, nie używa analityki ani reklam i nie udostępnia danych podmiotom trzecim.
- Dostęp można w każdej chwili cofnąć na https://myaccount.google.com/permissions.

---

**fakturobot** is a private tool run by its owner on their own server; it is not offered as a service to anyone else.
It uses the Gmail API only with the `gmail.send` scope, to send invoice e-mails from the owner's account to the owner's accountant and an archive copy to the same account. It never reads, searches or deletes mail. The Google token is stored only on the owner's server, readable by the administrator only, and is not shared with anyone. No analytics, no ads, no third-party sharing. Access can be revoked at any time at https://myaccount.google.com/permissions.
